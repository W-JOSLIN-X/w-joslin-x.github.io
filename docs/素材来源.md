## 头像与字体

头像使用站主提供的图片。默认组合保留 Zen Maru Gothic 与原有 loli 字体；原文件仍在 `src/assets/fonts/`。新增字体均从公开开源发行源获取并保存到本仓库，访客浏览时不调用 Google Fonts 或其他外部字体服务。

| 字体 | 发行来源 | 本地许可 |
|---|---|---|
| Resource Han Rounded CN v0.990 | https://github.com/CyanoHao/Resource-Han-Rounded | `public/fonts/rounded-OFL.txt` |
| LXGW WenKai Regular | https://github.com/lxgw/LxgwWenKai | `public/fonts/wenkai-OFL.txt` |
| Nunito、Klee One、Noto Sans/SC/JP、Noto Serif/SC/JP | https://github.com/google/fonts | `public/fonts/*-OFL.txt` |
| Zen Maru Gothic Medium | https://github.com/google/fonts/tree/main/ofl/zenmarugothic | `public/fonts/zen-maru-OFL.txt` |

详细资源网址见 `public/fonts/sources.json`；分片保留字形及许可，分片内部名称使用 Roxy 系列名称。静态字体声明真实字重：Zen Maru 500，原有 loli/文楷/资源圆体 400；其他字体使用发行 CSS 中的 400/700（Klee One 为 400/600）。原有 loli 来自既有主题资源，本轮不重新宣称其上游授权。代码与第三方组件许可证保留在仓库根目录。

## 2026-09-24 交互采样音

- 发行源：[Kenney Interface Sounds 1.0](https://kenney.nl/assets/interface-sounds)，官方页面及压缩包内 License.txt 均标为 CC0。2026-09-24 核实。
- 原始包和许可：`assets/audio/interface-sounds/`；逐项原文件名、处理后时长、电平、SHA-256：`assets/audio/interface-sounds/processing.json`。
- 发布文件：`public/audio/clicks/`，八种独立 WAV：mechanical、impact、wood、pluck、bubble、confirm、energy、arcade。
- `python scripts/prepare-click-sounds.py` 可重现转换（需要 ffmpeg）。单声道 44.1kHz PCM；裁剪静音、2ms 起音/5ms 尾音淡化；目标 RMS −20dBFS、峰值上限 −3dBFS，保留瞬态动态。峰值限制优先，因此部分高瞬态音的 RMS 较低。
