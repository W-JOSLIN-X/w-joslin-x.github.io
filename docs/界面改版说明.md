# 界面改版说明

本说明对应 v2.0.0。网站：https://w-joslin-x.github.io/ 。本地预览：http://127.0.0.1:4322/ 。部署状态以仓库 GitHub Actions 为准。

## 外观

参考 https://mizuki.mysqil.com/ 的组件视觉，保留左侧筛选／目录、中间文章、右侧个人资料的布局。

- 导航顶端有白色渐变透明衬底，随滚动渐显实色背景；菜单淡入、箭头旋转；搜索默认仅放大镜，悬停或键盘聚焦展开，手机点击展开。
- 首页横幅只有图片。文章页横幅更短，独立背景继续生效。
- 侧置封面卡片、可点击标签、浅主题色控件、大头像和图标入口。
- 使用 Mizuki 已附带的 Zen Maru Gothic 与 Loli 字体文件，本地加载；日语字体与参考站一致。
- 主题色滑杆与原生调色盘联动，统一驱动背景底色、标签、按钮、日历、标题标记。默认紫色 #8a72ee，白色内容面板。
- 横幅／全屏／叠加／隐藏，柔化、波浪、列表／网格、宽屏均可切换。正文保持稳定。
- 界面支持中／英／日；文章内容、用户标签与格言不自动翻译。偏好保存在浏览器 `roxy-appearance-v3`，可迁移旧版本设置。
- 桌面两侧整栏不再设置内部滚动区域，个人资料、日历、统计随页面滚动；音乐卡片可吸顶。手机抽屉保留必要的触摸滚动。

## 轮播与屏保

默认开启，15 秒切换，顺序循环，1 秒淡入淡出；可暂停、上一张／下一张、调整 3–300 秒间隔、随机播放。减少动态效果的系统偏好会取消淡入淡出。隐藏标签页暂停计时。

`/wallpapers/` 仅选择网站现有图片，支持勾选与上下移动排序，至少保留一张。设置保存在当前浏览器 `roxy-slideshow-v1`，不会修改他人的默认图库。不提供上传或外链导入；页面折叠说明链接到 GitHub 图片目录和配置文件。

文章独立背景在正常阅读时优先且保持静止；其他页面使用公共图库。屏保通过网页全屏覆盖隐藏导航和文章，不强制切换浏览器的 F11 模式。手动进入适用于所有页面；默认空闲 5 分钟自动进入，仅适用于非文章页，可关闭或调整 1–60 分钟。后台标签页、正在填写的输入框、打开的外观面板／抽屉和正在播放的媒体不会触发自动进入。

屏保始终使用勾选的公共图库，图片完整显示；鼠标移动、触摸或键盘操作唤出控制，3 秒后淡出。Esc／退出恢复原阅读位置，文章独立背景不受影响。不会自动开始音乐。图库文件失效时跳过该图，全部失效则保留原背景且停止切换。

## 音乐播放器更新

圆形旋转封面、歌曲信息、时间／音量、细进度条、居中的大播放按钮及下方歌单参考用户提供截图。主题色和中英日界面跟随全站设置，播放时封面旋转并显示歌单跳动标记，减少动态效果时关闭动画。默认不自动播放。

`src/config/music.ts` 集中维护歌曲 id、音频、封面、名字和作者，`public/music/` 按歌曲目录存放文件；空音源为不可播放的占位，循环／随机自动跳过。构建检查所有歌单中的本地音频与封面路径，重复 id 会阻止构建。详见 `public/music/README.md`。

支持列表循环、单曲循环、随机、上下曲、拖动进度、静音及音量、收起歌单。浏览器记住音量、模式、选中歌曲及进度；整页导航后需要手动继续播放。用户提供的 WAV 已转为较小的 MP3 用于网页，原始文件保留。

播放器验证：构建与类型检查通过（335 文件，0 错误／警告），12 项测试通过，12 个 HTML 页面和 539 个站内链接／资源检查通过。浏览器实测音频时长 172.522667 秒，播放时间正常增长；拖动到 17.3 秒并刷新可恢复且保持暂停；单曲播放结束后重播，音量／静音、歌单折叠、上下曲正常；390px 手机抽屉无横向溢出，浅色和深色外观已检查，控制台无错误。

## 搜索与日期

`/browse/` 是筛选结果页，按首次发布时间排列，使用年份时间线。分类栏、左侧标签、卡片标签和日历进入同一页面。搜索、类型、标签、情绪、日期可以叠加；主题标签全部匹配，情绪任意匹配。每次展示 12 篇。

日历周一开始，月份可前后切换，点击月份标题返回本月。今日以北京时间判断。深浅表示当日内容 Git 提交数；点日期筛选当日发布、标记更新、或真实 Git 提交修改过的现存文章。图片等资源修改按文章目录关联。日期结果下方保留真实提交链接。
