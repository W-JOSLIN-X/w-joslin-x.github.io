# Roooooxy’s BLOG v2.0.0

保留左侧导航、中间文章、右侧个人资料的三栏布局，更新参考 Mizuki 的组件外观，并加入背景轮播、屏保和可维护歌单的音乐播放器。

## 界面与阅读

- 顶部渐变透明导航、滚动渐显背景、悬停展开搜索和菜单动画。
- 侧置封面文章卡片、可点击标签、时间线筛选结果页；搜索与类型、标签、情绪、日期联合筛选。
- 更大的头像、按月切换的活动日历和站点统计；取消桌面两侧整栏内部滚动。
- 默认紫色主题、自由调色盘、中英日界面、深浅模式、横幅／全屏／叠加背景、柔化与波浪动画。
- RSS、Atom 和站点地图入口。

## 背景轮播与屏保

- 默认每 15 秒顺序切换，1 秒淡入淡出；可调整间隔、随机播放、暂停及上下张。
- 独立图库设置页支持勾选和排序，附仓库图片目录入口。
- 文章独立背景在阅读时保持静止；屏保使用公共图库，退出恢复背景及阅读位置。
- 默认非文章页空闲 5 分钟进入屏保，可关闭或调整；文章页只能手动进入，不自动播放音乐。

## 音乐播放器

- 圆形封面、进度拖动、音量与静音、上下曲、循环／随机模式、可折叠歌单和占位项。
- 接入用户提供的《尼古喵喵》OP 音频，网页使用约 4.14 MB 的 MP3，原 WAV 保留在本地。
- 新歌只需在 `src/config/music.ts` 填写歌名、作者、音频与封面；文件放在 `public/music/`。
- 音量、模式与进度保存在当前浏览器。整页导航后音乐暂停，需要手动继续。

## 验证

构建与类型检查通过，12 项自动测试通过；桌面与 390px 手机布局、播放与进度恢复、轮播及屏保边界已验证。发布工作流再次执行测试、构建和站内资源检查。
