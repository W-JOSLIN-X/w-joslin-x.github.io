## 一篇文章，一个目录

这篇示例包含一张站主提供的头像图片，用来验证本地图片渲染与 ZIP 下载。

![站主提供的黑白人物头像](./images/avatar.jpg)

## 下载时会发生什么

包含本地图片的文章会自动生成一个 ZIP，里面有 Markdown 原文和图片。打开压缩包中的 Markdown，图片仍然能通过相对路径显示。

## 外部资源

外链图片保留原链接，不会自动下载。其他附件可以放在 GitHub 仓库中，并在文章中添加链接。
